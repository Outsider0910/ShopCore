# 菜单与交互规范

> 适用范围：ShopCore 打开的全部 6×9 菜单。
> 目标：槽位稳定、点击可预期、刷新不卡主线程、文字风格统一。

## 1. 通用规则

- 所有菜单固定 54 格（6 行 × 9 列），内容区为 0~44。
- 菜单标题、物品名称、Lore、聊天提示一律 MiniMessage，并强制 `ITALIC=false`。
- 点击/拖拽一律取消，只响应 `ShopMenuHolder` 动作表登记的槽位；
  不信任物品 PDC、客户端槽位或客户端物品。
- 所有按钮通过 `UiItems.create(...)` 创建，带 `shopcore:ui_id` 与
  `custom_model_data`；完整 ID 见 [`components.md`](./components.md)。
- 展示物品必须是商品/寄售的克隆，不能修改原始组件。
- 渲染路径不得做数据库/HTTP/阻塞 IO。

## 2. 底部导航

使用通用导航的页面：

| 槽位 | 作用 |
| --- | --- |
| 45 | 返回上一级（菜单内部） |
| 48 | 上一页；不可用时灰色玻璃板 |
| 49 | 页码（`第 x / y 页`） |
| 50 | 下一页；不可用时灰色玻璃板 |
| 53 | 返回主菜单 |

"返回主菜单"必须：

1. 下一 tick 调 `MainMenuApi.openOrNull(player)`。
2. 返回 `false` 或旧版 MainMenu 无该 API 时执行 `/cd`。
3. 不得用 `player.closeInventory()` 代替。

内容区 0~44；加载中在 22 放时钟；空列表在 22 放提示物品；
渲染失败在 22 放红色玻璃板并保留 53 返回主菜单。

## 3. 主菜单

| 槽位 | 内容 | 说明 |
| --- | --- | --- |
| 4 | 钱包余额 | 绿宝石；Wallet 同款余额行；点击打开钱包流水 |
| 19 | 官方商店 | 打开官方商品页 |
| 21 | 玩家商店 | 打开玩家寄售页 |
| 23 | 我的上架 | 打开自己的寄售 |
| 25 | 待领取 | 打开邮箱 |
| 27 | 货币兑换 | 打开兑换方向页 |
| 40 | 返回主菜单 | 屏障 |
| 45 | 商店管理 | 仅 OP / `shopcore.admin` 可见 |

其余槽位为灰色玻璃板。

余额按钮规范：

- 材质 `EMERALD`，名称"钱包"，白色。
- Lore：每行 `货币名：余额 符号`；未绑定显示"未绑定网站账号"；无缓存显示"…"；
  底部"点击查看流水"。
- 每秒重绘一次；Wallet 余额按玩家 5 秒节流异步刷新；只读 Wallet 缓存。
- 本服启用货币与 Wallet `assets.yml` / `config.yml` 同口径。

## 6. 我的上架 / 待领取

"我的上架"：内容区列出自己的寄售；通用导航；返回目标是玩家商店。

"待领取"：内容区列出邮箱条目；通用导航；51 为"领取全部"。
点击条目或 51 都会尝试把邮箱物品放进背包，背包满则留在邮箱。

## 7. 货币兑换

| 槽位 | 内容 |
| --- | --- |
| 0~44 | 可兑换方向 |
| 45 / 48 / 49 / 50 / 53 | 通用导航 |

方向条目显示 `1 源币 = rate 目标币`；点击后关闭菜单，聊天输入源币数量，
再点击确认。没有可用方向时显示原因（兑换关闭 / Wallet 未就绪 / 没有配置方向）。

## 10. 选择物品 / 选择货币

选择物品：

| 槽位 | 内容 |
| --- | --- |
| 0~35 | 镜像玩家主背包 |
| 36~53 | 灰色玻璃板 |
| 45 | 返回上一级 |
| 53 | 返回主菜单 |

选择货币：

| 槽位 | 内容 |
| --- | --- |
| 0~44 | Wallet 官网 + 本服启用的货币 |
| 45 | 返回上一级 |
| 53 | 返回主菜单 |

货币条目显示名称、code、精度；`money=true` 用金锭，其余用绿宝石。
点击后：玩家上架/官方商品进入价格输入；管理员改币种直接更新商品。

## 11. 刷新与状态

| 页面 | 刷新时机 |
| --- | --- |
| 主菜单余额 | 每秒重绘；Wallet 余额 5 秒节流异步刷新 |
| 其他页面 | 打开/翻页时异步加载 |
| 钱包流水 | 打开/翻页时异步加载 |
| 管理页 | 打开/编辑后重新加载 |

状态物品：

- 加载中：22 时钟。
- 空列表：22 灰色玻璃板 + 灰色提示。
- 加载失败：22 红色玻璃板 + 错误提示，53 可返回主菜单。
- 不可用/未启用：红色玻璃板或红色提示，不提供无效点击。

## 12. 文字与资源包

- 所有 UI 名称/Lore/标题/聊天文案不得斜体；`UiItems` 与 `Messages` 已统一处理。
- UI ID 是服务端与资源包的稳定契约；改 ID 前先更新
  [`components.md`](./components.md)。
- 带 `shopcore:ui_id` 的物品禁止上架/寄售。
